# 🌑 Shadow Monarch

**Your Personal AI Command Center**

Shadow Monarch is a futuristic AI interface designed to bring AI conversations, intelligent tools, and productivity features together in one place.

## ✨ Features

- 💬 AI Chat Interface
- 🧠 Multiple AI Model Support
- 🛠️ AI Tools and Command Center
- 👁️ Vision and image-analysis features (where supported)
- 🎨 Futuristic, dark-themed interface
- 📱 Browser-based interface

## 🚀 Getting Started

### Run Locally
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Open Settings and configure your own API key if required.
4. Select a supported AI model and test the chat.

### Live Website
Once GitHub Pages is enabled, open the website using the URL provided in your repository's **Settings → Pages** section.

## 🔑 API Key Security

- Never commit API keys or other secrets to the repository.
- API keys saved in browser storage are not included in the HTML upload, but they are not fully protected from JavaScript running on the page.
- For a public website serving multiple users, use a backend to keep API keys on the server.

- ## 👁️ YOLO Object Detection

- Object detection using a compatible YOLO model.
- Detect and identify supported objects in images or camera input.
- Actual functionality depends on the configured model and inference setup.

## 🔮 Hologram Interface

- Futuristic hologram-style visual interface.
